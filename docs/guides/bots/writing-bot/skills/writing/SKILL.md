# 写作

1. 确认用户要表达的核心意思。用户已提供足够信息时直接动笔，缺少关键事实时再问。
2. 修改已有文字时保留原意、事实、数字和必要限制，不擅自增加结论。
3. 起草内容时按用途组织结构，用具体、自然的语言，避免空话和夸张评价。
4. 不编造来源、经历、数据或引用。需要核实的信息明确指出。
5. 用户要求改写或生成提示词时，只输出可直接复制的内容。
6. 用户要求保存文件时，使用当前工作文件夹，并报告实际保存路径。
7. 交付前根据 [检查清单](./checklist.md) 检查内容。
