# TheOne 万能助手

**ALL IN ONE，你的全能 AI Agent。**

把想法变成可执行的任务，让不同专长的 AI 助手共同完成工作。

TheOne 面向个人开发者、创作者和小团队：从一句需求出发，在同一个工作空间里完成任务拆解、资料调研、文件处理、内容创作与结果整理。你可以看到谁在做什么，也可以随时补充要求、停止执行或检查交付。

## 核心能力

- **多助手协作**：主任务分派前端、后端、设计等子任务；子任务可以继续分派，左侧以层级缩进展示任务关系。
- **先调研，再确认**：子任务查找网上案例和可复用技能，列出来源与实施方案，获得确认后继续开发。
- **Bot 广场**：点击专用助手直接开始对话，支持从本地文件或 GitHub 链接导入 Bot。
- **按你的水平交流**：每个会话可以独立设置学习水平，让讲解方式适合当前话题和使用者。
- **文件与项目工作**：读取、创建和修改文件，查看目录、预览内容与代码改动；也可以不选文件夹直接聊天。
- **作图助手**：接入真实图像服务，在对话中生成图片素材。图像服务需要单独配置。
- **文章库**：整理和阅读 AI 情报、文章与长文内容。
- **电脑操作**：连接桌面操作能力，让助手观察界面并执行操作；需要相应驱动和系统权限。
- **模型与会话管理**：支持 ChatGPT 授权及模型服务配置，提供流式回复、停止、追加指令、排队、历史恢复与会话分支。

## 一个典型任务

> 做一个企业官方网站。

主助手拆解目标，前端助手研究页面与交互，后端助手研究数据和服务；前端可以继续委派视觉设计。各子任务先提交调研来源与方案，你确认后继续实施。主任务检查并整合交付文件，保留可追溯的会话和任务记录。

## 开始使用

1. 打开 TheOne，在设置中完成 ChatGPT 授权或配置可用的模型服务。
2. 新建对话，或在 Bot 广场选择一个专用助手。
3. 输入你的目标；涉及项目文件时，在输入框上方选择工作文件夹。
4. 查看任务分工、工具执行与交付结果；根据需要确认方案或补充要求。

模型和图像服务的可用性取决于你的账户权限、服务额度与配置。
